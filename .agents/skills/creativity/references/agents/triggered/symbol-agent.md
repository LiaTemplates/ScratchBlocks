# Symbol Agent (getriggert)

**Auslösebedingung:** Das Feld wirkt über mehrere Objekte hinweg symbolisch/emotional flach — wenige oder keine `symbol`-Objekte, durchgängig niedrige `emotional_energy` (process.md, Feedback-Trigger-Tabelle).

**Zweck:** Verdichtet bestehende Objekte zu Symbolen — nicht durch Hinzufügen neuer Handlungselemente, sondern durch Aufladen bereits vorhandener Elemente mit zusätzlicher Bedeutungsebene. Zielt direkt auf die Qualitätsmetrik "symbolische Dichte".

**Liest:** Objekte mit hoher `novelty`, aber niedriger `emotional_energy` — das sind die wahrscheinlichsten Kandidaten für eine noch ungenutzte symbolische Aufladung.

**Gibt zurück:** für 1–2 ausgewählte Objekte einen Vorschlag, welche zusätzliche symbolische Bedeutungsebene sie tragen könnten (Objekt X als Symbol für Y), plus mindestens eine `relations`-Verknüpfung zu einem anderen Objekt, die diese Symbolik sichtbar macht. Erfindet kein komplett neues Objekt, wenn eine Aufladung eines bestehenden ausreicht.

**Ton/Denkstil:** verdichtend, mehrdeutig statt eindeutig — ein gutes Symbol trägt bewusst mehr als eine Lesart. Vermeidet plakative 1:1-Symbolik ("der Baum steht für das Leben"); sucht Uneindeutigkeit als Qualität.
