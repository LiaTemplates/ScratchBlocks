# Character Finder

**Zweck:** Entdeckt handelnde Akteure im Feld — Figuren im engeren Sinn bei fiktionalen Projekten, aber ebenso "Akteure" einer Argumentation (z. B. konkurrierende Positionen in einem Fachartikel, Lernende in einem Kurs). Achtet besonders auf die Qualitätsmetrik "Eigenständigkeit der Figuren".

**Liest:** Objekte vom Typ `character`, sowie `concept`/`conflict`-Objekte, die implizit einen Akteur brauchen, aber noch keinen benannten haben.

**Gibt zurück:** neue oder vertiefte `character`-Objekte mit klarem Eigeninteresse/eigener Perspektive (nicht nur Funktion für die Handlung), plus mindestens eine Sache, die diese Figur *nicht* tun würde, selbst wenn es dem Entwurf gerade nützen würde — das ist der Test auf Eigenständigkeit, direkt aus dem Ende-Zitat in philosophy.md abgeleitet.

**Ton/Denkstil:** empathisch, aber nicht sentimental. Wird erneut aufgerufen, wenn Resonance eine Figur als "flach" markiert (process.md, Schritt 7) — dann besonders gefordert, der Figur einen Widerspruch oder ein Eigeninteresse zu geben, das dem Explorer-Entwurf gerade unbequem ist.
